Modules (syllabus outline)

  • Introduction to Computer Networks and Layered Architectures
  • OSI and TCP/IP Models
  • Protocol Hierarchies and Network Design principles
  • Data Communication Concepts
  • Serial and Parallel Communication
  • Simplex, Half-Duplex and Full-Duplex Communication
  • Switching Techniques and Multiplexing Methods including TDM, FDM, WDM and Statistical Multiplexing
  • Error Detection and Correction Techniques — CRC, Checksum, Hamming Code, Forward Error Correction and ARQ
  • Network Performance Metrics
  • QoS and Traffic Management
  • Internet Protocol Suite; IPv4 and IPv6 Addressing, Subnetting and CIDR
  • TCP, UDP, ICMP, DHCP, DNS, HTTP/HTTPS, SMTP, FTP/SFTP, SSH, SNMP, RTP and VoIP
  • Routing and Switching Fundamentals
  • Static and Dynamic Routing protocols including OSPF, BGP and MPLS
  • SD-WAN Concepts
  • Wireless Networking including Wi-Fi 6/6E, 5G and Introduction to 6G
  • Cloud, Edge and IoT Networking Fundamentals
  • Zero Trust Networking and Secure Access Service Edge (SASE) Concepts
  • Guided and Unguided Transmission Media — Fiber optics, Twisted Pair, Coaxial and Wireless Media
  • Ethernet and Modern LAN Technologies
  • Physical and Logical Topologies
  • Network Devices — Switches, Routers, Gateways, Firewalls, Access Points and Modems
  • Data Center Networking and Virtual LANs (VLANs)
  • Network Operating Systems, Virtualization, Container and Kubernetes Networking
  • Network Security, Access Control, Monitoring, QoS, Fault Management and Disaster Recovery
  • Software Defined Networking (SDN)
  • Network Function Virtualization (NFV)
  • AI-driven Network Management
  • Network Automation using Python and Ansible
  • Devops for Networking
  • Practical Networking using Wireshark, Packet Tracer and GNS3
